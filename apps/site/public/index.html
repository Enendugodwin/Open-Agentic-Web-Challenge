    For agent builders

    This store publishes an open agent network that conforms to the Worldwide Agentic Web MVP profile. A conforming runtime on another origin, such as a recipe site, can load it after its user approves, and run it in that user's browser with the caller's own model.

    • Peer network URL: /agents/market_assistant
    • agent-manifest.json · market_assistant.network.json · links.json (CORS enabled)
    • Public read-only MCP server: /api/mcp/public (tools match_ingredients, search_products)
    • Cart changes stay on this site: the add_to_cart action runs only here, after the shopper confirms.
    Greenleaf Market is fictional. Products, prices and stock are generated for demonstration. Checkout is not available.
